Error handling

throw(message) raises an error. A try block runs its statements; if an error is raised inside it, including in functions it calls, the rest of the block is skipped and the catch block runs. The name in catch (name) receives the message as a str and can be omitted (catch : ().

func withdraw(balance : int, amount : int) : int : (
    if (amount > balance) : ( throw("not enough money") )
    return : int (balance - amount)
)

try : (
    val left = withdraw(10, 50)
    println(left)
)
catch (problem) : (
    println("Could not withdraw: " + problem)
)

Vamp raises its own errors in the same way, so they can be caught too: whole-number division or % by zero, an invalid list index, a missing map key, an invalid string index, list.pop() on an empty list, using a field or method on none, a file that cannot be read, invalid JSON, invalid text in int(...), and others mentioned with each library. An uncaught error prints Error: message and exits with code 1.

assert(condition) raises an error when the condition is false; assert(condition, "message") adds a custom message. The error includes the file and line.
