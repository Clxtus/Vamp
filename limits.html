Limits

These limits were measured on Windows 11 with a 64-bit build. Exceeding any of them produces an error message rather than a silent crash.

What Limit
Recursion depth The main thread has a 64 MB stack, enough for about a million calls of a small function. Each thread.Start thread has 16 MB. Deeper recursion ends the program with Error: stack overflow.
List length 2,147,483,647 values (memory permitting).
Map and set size 536,870,912 entries.
String length 2,147,483,647 bytes.
Threads 1024 started threads that have not been joined. Join finished threads to start more.
Integers int wraps around on overflow, as in C (9223372036854775807 + 1 is the smallest int). Dividing the smallest int by -1 gives the smallest int.
Nesting in source code At least 3,000 nested blocks, and expressions of about 30,000 terms. Deeper code produces a compile error asking for it to be split up.
Regular expressions A pattern that takes too long to match (like (a+)+b on a long string) raises an error instead of hanging.
JSON Documents nested more than 512 levels deep are rejected.

Building a long string with text = text + piece in a loop copies the text every time. For thousands of pieces, use a builder or list.join, which are much faster.

A crash that is not a Vamp error, such as accessing freed native memory, prints Error: invalid memory access and exits with code 1.
