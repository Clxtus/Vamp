math

Every function accepts any number type. The result is a float, or an f32 if every argument was an f32.

Call Result
math.Sqrt(x), math.Pow(base, exponent) Square root and power.
math.Sin(x), math.Cos(x), math.Tan(x) Trigonometry, in radians.
math.Asin(x), math.Acos(x), math.Atan(x), math.Atan2(y, x) Inverse trigonometry.
math.Exp(x), math.Log(x), math.Log10(x) Exponential and logarithms.
math.Floor(x), math.Ceil(x), math.Round(x) Rounding. The result is still a float, so use int(math.Floor(x)) for a whole number.
math.Abs(x), math.Min(a, b), math.Max(a, b), math.Clamp(x, low, high) When every argument has the same whole-number type, the result has that type too (math.Max(3, 9) is the int 9).
math.Lerp(a, b, t) a + (b - a) * t.
