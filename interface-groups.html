Interface groups

A group is a named set of controls in one window, such as a HUD or a pause menu. Group functions act on every control in the group at once, so switching screens does not require listing each control.

A control is added to a group with the group property at creation, or later with os.Set_Interface_Group:

import os
import input

val window = os.Make_Window("Game")

val score = os.Make_Interface("label", "Game", "score", (
    size = (120, 30),
    position = (10, 10),
    text = "Score: 0",
    group = "hud"
))
val lives = os.Make_Interface("label", "Game", "lives", (
    size = (120, 30),
    position = (10, 45),
    text = "Lives: 3",
    group = "hud"
))
val resume = os.Make_Interface("button", "Game", "resume", (
    size = (160, 40),
    position = (320, 200),
    text = "Resume",
    visible = false,
    group = "pause"
))
val quit = os.Make_Interface("button", "Game", "quit", (
    size = (160, 40),
    position = (320, 250),
    text = "Quit",
    visible = false,
    group = "pause"
))

val paused : bool = false
while (true) : (
    if (input.Key_Pressed("ESCAPE") and not paused) : (
        paused = true
        os.Switch_Interface_Group("Game", "pause")      // show the pause menu, hide the HUD
    )
    if (os.Interface_Clicked("Game", "resume")) : (
        paused = false
        os.Switch_Interface_Group("Game", "hud")
    )
    if (os.Interface_Clicked("Game", "quit")) : ( exit(0) )
    os.Sleep(16)
)
Call Description
os.Make_Interface_Group(window_title, group) Declares an empty group. This is not needed for a group already used in a group property or os.Set_Interface_Group. Returns true.
os.Set_Interface_Group(window_title, name, group) Moves the control into the group, leaving its previous group. An empty name "" removes it from every group. Returns whether the control exists.
os.Interface_In_Group(window_title, name, group) Whether the control is currently in the group.
os.Show_Interface_Group(window_title, group), os.Hide_Interface_Group(window_title, group) Shows or hides every control in the group.
os.Set_Interface_Group_Visible(window_title, group, visible) The same, with a bool.
os.Switch_Interface_Group(window_title, group) Shows this group's controls and hides every other group in the window. Controls that are in no group are left unchanged.
os.Set_Interface_Group_Enabled(window_title, group, enabled) Enables or disables every control in the group.
os.Move_Interface_Group(window_title, group, dx, dy) Moves every control in the group by dx and dy pixels.
os.Remove_Interface_Group(window_title, group) Destroys every control in the group, like os.Remove_Interface does for one. The group itself can be filled again.

Functions that act on a group return the number of controls they changed, as an int (0 for an empty group).

Rules:

  • A control is in at most one group. A group belongs to one window, so two windows can each have a group named "hud".
  • Window titles, control names and group names must be string literals, as with every interface function.
  • A group name that no control ever joins and that os.Make_Interface_Group never declares is a compile error, which catches misspelled names.
  • A control removed with os.Remove_Interface leaves its group.
  • Group functions use the same safe messaging as single-control functions, with one message per control.
