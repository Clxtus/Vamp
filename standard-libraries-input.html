input

input reads the keyboard and mouse directly, whether or not the program's window has focus.

Call Result
input.Key_Down(key) Whether the key is currently held down.
input.Key_Pressed(key) true once each time the key is pressed. Call it every frame.
input.Mouse_Down(button) button is "left", "right" or "middle".
input.Mouse_X(), input.Mouse_Y() Mouse position on the screen, in pixels.
input.Mouse_Window_X(title), input.Mouse_Window_Y(title) Mouse position inside the window with that exact title, or -1 when there is no such window.

A key is a letter ("A"), a digit ("7"), or one of "SPACE", "ENTER", "ESCAPE", "TAB", "BACKSPACE", "DELETE", "INSERT", "LEFT", "RIGHT", "UP", "DOWN", "HOME", "END", "PAGEUP", "PAGEDOWN", "SHIFT", "CTRL", "ALT", "LSHIFT", "RSHIFT", "LCTRL", "RCTRL", "CAPSLOCK", "PLUS", "MINUS", "COMMA", "PERIOD", "F1" to "F12". Letter case does not matter. An unknown name is an error.

import os
import input

val window = os.Make_Window("Game")
val x : int = 100
while (!input.Key_Down("ESCAPE")) : (
    if (input.Key_Down("LEFT")) : ( x -= 4 )
    if (input.Key_Down("RIGHT")) : ( x += 4 )
    os.Sleep(16)
)
