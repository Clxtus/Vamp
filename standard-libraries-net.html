net

import net

val connection : int = net.Connect("example.com", 80)
if (connection == 0) : ( throw("could not connect") )
net.Send(connection, "GET / HTTP/1.0\nHost: example.com\n\n")
println(net.Receive(connection, 4096))
net.Close(connection)

println(net.Http_Get("https://example.com/"))
Call Result
net.Connect(host, port) Opens a TCP connection. Returns its number, or 0 on failure.
net.Listen(port) Starts accepting TCP connections on a port. Returns the listener's number, or 0.
net.Accept(listener) Waits for a client and returns a connection to it, or 0.
net.Send(connection, text) Sends all of the text. Returns the number of bytes sent, or -1.
net.Receive(connection, limit) Waits for data and returns up to limit bytes; "" when the other side has closed the connection.
net.Close(connection) Closes a connection or listener.
net.Http_Get(url) Downloads an http or https address and returns the body as text. Raises an error on failure.
net.Download(url, path) Downloads to a file; returns whether it succeeded.
net.Http_Post(url, body, content_type) Sends body to an http or https address and returns the reply, e.g. net.Http_Post(url, json.To_Text(doc), "application/json"). Raises an error on failure.
net.Set_Timeout(connection, milliseconds) Makes Receive and Send give up after the given time (Receive then returns ""). Returns whether it was set.

Accept and Receive wait, so a server usually runs them on a thread. Data is text, and a zero byte ends a received string.
