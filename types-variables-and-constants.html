Types, variables, and constants

The most common types are int, float, bool and str. int and float are the largest and most precise, and are the recommended defaults. The fixed-size types are intended for cases where size matters, such as large lists or binary file formats.

Type Holds
int (or i64) Whole numbers, 64-bit, signed (roughly ±9.2 × 10¹⁸).
i8, i16, i32 Signed whole numbers, 8, 16 and 32 bits.
u8, u16, u32, u64 Unsigned whole numbers, 8, 16, 32 and 64 bits.
float (or double) 64-bit decimal, about 15 significant digits.
f32 32-bit decimal, about 7 significant digits.
char One byte, in single quotes: 'A', '\n'.
bool true or false.
str Text. 
val population : int = 8000000000
val level : u8 = 200
val precise : float = 3.141592653589793
val letter : char = 'A'
val mask : int = 0xFF          // hex; 0b1010 is binary
val distance : float = 1.5e8   // 150000000.0; 2e-3 is 0.002

A number literal takes the type it is used with, so val small : i32 = 5 and small + 1 need no conversion. A literal that does not fit (val level : u8 = 300) will not compile. Values of two different number types are never mixed implicitly; convert one side, for example int(small) + count. i64 and int are the same type, and so are double and float, so they mix freely. A whole-number literal too large for int is a u64.

val count : int = 10
const title : str = "Vamp"
  • val declares a mutable variable.
  • const declares an immutable constant and requires both a type and a value.
  • A single val can omit its type when the value determines it.
  • A typed val with no value starts with the default value: 0, 0.0, false, "", an empty list or map, or a struct with every field set to zero.
  • A variable declared at the top of a file (outside any function, loop or if) is global. Every function in the file can read and modify it, including functions declared above it.

Several variables of the same type can be declared together:

val x, y, z : int = 10, 20, 30
val first, second, third : int

When values are given, there must be one for each name.

To convert a value, call the target type like a function:

val whole : int = int(3.8)
val message : str = str(whole)
val decimal : float = float(whole)
val enabled : bool = bool(1)
val small : i32 = i32(whole)
val code : int = int('A')        // 65
val text : str = str('A')        // "A"

Every number type has a conversion call (i8(...) through u64(...), f32(...), double(...), char(...)). Converting to a smaller type keeps the low bits, so u8(300) applied to a variable gives 44.

int(text) and float(text) raise an error that can be caught with try if the text is not a number or does not fit, like int("abc"). Surrounding spaces are allowed. For user input, check the text with text.is_number() first.
