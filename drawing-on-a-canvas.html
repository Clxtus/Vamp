Drawing on a canvas

A canvas control is a drawing surface for games, charts and custom controls. Drawing goes to a hidden image that appears when os.Present is called, so a frame is never shown half drawn.

import os

val window = os.Make_Window("Game", ( size = (520, 400) ))
val screen = os.Make_Interface("canvas", "Game", "screen", (
    size = (480, 320),
    position = (10, 10),
    background_color = "#101820"
))

val x : int = 0
os.Every(16, func () : (
    x = (x + 4) % 480
    os.Canvas_Clear("Game", "screen", "#101820")
    os.Fill_Circle("Game", "screen", x, 160, 20, "orange")
    os.Draw_Text("Game", "screen", 10, 10, f"x = {x}", "white", 16)
    os.Present("Game", "screen")
))
os.Run_Events()
Call Description
os.Canvas_Clear(window, name, color) Fills the whole canvas.
os.Fill_Rect / os.Draw_Rect(window, name, x, y, width, height, color) A filled or outlined rectangle.
os.Draw_Line(window, name, x1, y1, x2, y2, color) A line.
os.Fill_Circle / os.Draw_Circle(window, name, x, y, radius, color) A filled or outlined circle centred on (x, y).
os.Draw_Text(window, name, x, y, text, color, size) Text with its top-left corner at (x, y).
os.Draw_Image(window, name, path, x, y, width, height) A PNG, JPEG, BMP, GIF or ICO image scaled into the rectangle; returns whether it loaded. Images are loaded once and cached.
os.Present(window, name) Shows what was drawn since the last Present.
os.Save_Canvas(window, name, path) Saves the drawing as .png, .jpg or .bmp; returns whether it succeeded.
os.Canvas_Width(window, name), os.Canvas_Height(window, name) The canvas size in pixels.

Colors are "#RRGGBB" or one of "black", "white", "red", "green", "blue", "yellow", "orange", "purple", "gray". Positions are pixels from the canvas's top-left corner, and drawing outside it is clipped. Shapes are written directly into the image's pixels, so thousands of shapes per frame are inexpensive. A canvas reports clicks like a button (os.Interface_Clicked, os.On_Click), and input.Mouse_Window_X / Y give the mouse position within the window.
