The os library

Files and folders

Call Description
os.Make_Directory(path) Creates the folder and any missing parent folders. Returns 0 on success or a Windows error code.
os.Get_Directory(path) The absolute path of an existing folder; relative paths start from the working directory. On failure, it prints an error and returns "".
os.List_Directory(path) Prints the folder's entries one per line, omitting . and ... Returns the entry count, or -1 on failure.
os.Remove_Directory(path) Deletes a folder and its contents. Returns whether it succeeded.
os.Directory_Exists(path) Whether the path exists and is a folder.

Programs, arguments and the environment

Call Result
os.Args() The command line as a list[str]. The first entry is the program itself.
os.Get_Env(name) An environment variable, or "" if it is not set.
os.Set_Env(name, value), os.Env_Exists(name) Sets a variable for this program and the programs it starts; checks whether one exists.
os.Run(command) Runs a command (as in the Windows command prompt), waits for it, and returns its exit code. Its output appears in the console.
os.Run_Output(command) The same, but returns everything the command printed.
os.Start_Process(command) Starts a command without waiting and returns its process number.
os.Process_Running(id), os.Wait_Process(id), os.Kill_Process(id) Whether it is still running; wait for it and get its exit code; stop it. 
import os
val args = os.Args()
if (args.length() > 1) : ( println("first argument: " + args[1]) )
println(os.Run_Output("git --version"))

Windows

val opened = os.Make_Window("Demo", (
    icon = "assets/app.png",
    size = (800, 600),
    resizable = true,
    type = "Windowed"
))

os.Make_Window(title, settings) creates a native Windows window and returns true on success. The settings are optional; the default is a resizable 800×600 window. Supported settings:

  • icon = "path": an ICO, PNG or JPEG, resolved from the working directory (the folder the program runs from). Any str expression can be used. If the icon cannot be loaded, a warning is printed and the window opens without it.
  • size = (width, height): positive whole numbers.
  • resizable = true or false.
  • type = "Windowed", "Full Screen", "Maximized" or "Borderless".
  • style = "classic", "native" (default) or "modern": the appearance of the controls. See Interface styles.
  • theme = "light", "dark" or "system": the colors of a "modern" window, including the title bar. "system" follows the Windows app theme. Only valid with style = "modern".

Other window functions:

Call Description
os.Launch_Window(executable_path) Starts another program. Returns true if Windows accepts the launch.
os.Remove_Window(title) Sends a close request to every visible window with that title; returns whether a request was sent.
os.Get_Window(title) Whether a visible window with the matching title exists.
os.List_Windows() Prints the titles of visible windows and returns their count.
os.Sleep(milliseconds) Waits while still handling messages for Vamp windows. Use it to pace a loop. A negative duration prints an error and does not wait.
os.Set_Window_Title(title, new_title) Renames the first visible window with that title; returns whether a window was renamed. A window created by the program remembers its original title, so its interface calls continue to use it.
os.Resize_Window(title, width, height) Sets the outer size in pixels (both must be positive). Position and stacking are unchanged. Returns whether the window was resized.
os.Move_Window(title, x, y) Moves the top-left corner to a screen position (negative values are valid on multi-monitor setups). Returns whether the window was moved.
os.Minimize_Window(title) Minimizes the window. Returns whether it was found.
os.Maximize_Window(title) Maximizes the window. Returns whether it was found.
os.Restore_Window(title) Restores a minimized or maximized window to its normal size. Returns whether it was found.
os.Focus_Window(title) Restores the window if it is minimized and asks Windows to bring it to the front. Returns whether Windows accepted the request; it may refuse for another program's window.
os.Set_Window_Icon(title, path) Sets the title bar and taskbar icon from an ICO, PNG or JPEG. Returns whether the icon loaded and was applied.
os.Get_Window_Width(title), os.Get_Window_Height(title) The outer size in pixels, or -1 if there is no visible window with that title.
os.Get_Window_X(title), os.Get_Window_Y(title) The top-left screen position, or -1 when there is no such window. (A window can also be positioned at -1.)
os.Window_Minimized(title), os.Window_Maximized(title) Whether the window is minimized or maximized; false if there is no such window.

All window functions identify windows by title, not by process name. Titles are matched case-insensitively against visible windows, and the first match is used (os.Remove_Window hits every match). A window created by the program stays open while the program runs and keeps it alive until the window is closed.
