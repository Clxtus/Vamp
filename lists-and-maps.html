Lists and maps

Arrays and dictionaries have a fixed size, while lists and maps grow and shrink as the program runs. They are declared with their type and filled with the same [ ] and { } literals.

Lists

val scores : list[int] = [10, 20]
val names : list[str] = []

scores.push(30)
scores[0] = 15
println(scores[2])
println(scores.length())

for (score) in (scores) : ( println(score) )
Method Result
list.push(value) Adds a value at the end.
list.pop() Removes and returns the last value.
list.insert(index, value) Inserts before index, shifting the rest up.
list.remove(index) Removes the value at index.
list.clear() Removes every value.
list.length(), len(list) The number of values.
list.is_empty() Whether the list has no values.
list.first(), list.last() First or last value.
list.contains(value) Whether the list contains the value.
list.index_of(value) Index of the first match, or -1.
list.sort() Sorts numbers low to high and strings alphabetically.
list.reverse() Reverses the order.
list.copy() A separate list with the same values.
list.join(separator) For list[str]: one string with separator between the values.
list.filter(keep) A new list with the values where keep(value) is true.
list.map(change) A new list of change(value) for each value; the element type is the type returned by change.
list.for_each(action) Calls action(value) on each value.
list.any(test), list.all(test) Whether test(value) is true for at least one value, or for all of them.
list.find_index(test) Index of the first value where test(value) is true, or -1.
list.reduce(combine, start) Folds the list into one value, calling combine(total, value) for each value, starting from start.
list.sort_by(comes_first) Sorts using a custom order: comes_first(a, b) returns true when a should come before b. Stable.

Elements can be of any type, including structs, classes and other lists (list[list[int]]). Reading or writing an index that does not exist raises an error that reports the index and the length, which can be caught with try.

Maps

A map stores a value for each key. Keys can be str, char or any whole-number type.

val ages : map[str, int] = {"Emma": 31, "Jake": 27}
ages["Lucy"] = 24
ages["Emma"] += 1

if (ages.has("Jake")) : ( println(ages["Jake"]) )
println(ages.get("Nobody", 0))

for (name) in (ages) : ( println(name + " is " + str(ages[name])) )
Method Result
map[key] = value, map.set(key, value) Adds the key or replaces its value.
map[key] The value for that key. A missing key raises an error (catchable with try).
map.get(key, fallback) The value, or fallback if the key is not there.
map.has(key) Whether the key is present.
map.remove(key) Removes the key; returns whether it existed.
map.length(), len(map) The number of keys.
map.is_empty(), map.clear() As for lists.
map.keys(), map.values() New lists of the keys or values, in the order the keys were added.

Lists and maps are shared, not copied: passing one to a function or assigning it to another variable creates a second reference to the same object. Use list.copy() when a separate copy is needed.

val scores : list[int] = [7, 2, 9, 4]
val high = scores.filter(func (s : int) : bool : ( return : bool (s > 5) ))      // [7, 9]
val labels = scores.map(func (s : int) : str : ( return : str (f"#{s}") ))     // ["#7", "#2", ...]
scores.sort_by(func (a : int, b : int) : bool : ( return : bool (a > b) ))      // highest first
println(scores[1:3])                                                          // [7, 4]

list[start:end] is a new list from start up to, but not including, end. Either side can be left out (xs[:2], xs[2:]), and negative numbers count from the end (xs[-2:] is the last two).

Sets

A set holds each value at most once, in the order the values were first added. Values can be str, char or whole numbers.

val seen : set[str] = {}
seen.add("Emma")
seen.add("Emma")
println(seen.length())                          // 1
val primes = {2, 3, 5, 7}
val odd : set[int] = {1, 3, 5, 7, 9}
println(primes.intersection(odd))               // {3, 5, 7}
Method Result
set.add(value), set.remove(value) Adds a value, or removes it (returns whether it was there).
set.has(value), set.contains(value) Whether the value is in the set.
set.length(), len(set), set.is_empty(), set.clear() As for lists.
set.union(other), set.intersection(other), set.difference(other) New sets.
set.is_subset(other) Whether every value is also in other.
set.values(), set.copy() The values as a list, or a separate copy of the set.

A for loop iterates over a set's values. println prints lists, maps, sets and tuples in the same form they are written: [1, 2], {"Emma": 31}, (1, "one").
