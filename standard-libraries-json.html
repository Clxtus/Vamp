json

A JSON document is a value of type json. Values inside it are reached with a path: names separated by dots, and [index] for array elements. An empty path "" refers to the document itself.

import json

val save = json.Load("save.json")
val name : str = json.Get_Str(save, "player.name")
val hp : int = json.Get_Int(save, "player.hp")
val first_item : str = json.Get_Str(save, "player.items[0]")

json.Set_Int(save, "player.hp", hp - 10)
json.Append_Str(save, "player.items", "key")
json.Save(save, "save.json")
free(save)
Call Result
json.Parse(text), json.Load(path) A document from text or from a file. Invalid JSON raises an error with the line and column.
json.New_Object(), json.New_Array() A new, empty document.
json.To_Text(doc), json.To_Pretty_Text(doc) The document as compact or indented text.
json.Save(doc, path) Writes indented JSON to a file; returns whether it was written.
json.Has(doc, path) Whether a value exists at the path.
json.Type(doc, path) "object", "array", "string", "number", "bool", "null", or "missing".
json.Length(doc, path) The number of elements in an array or members in an object.
json.Keys(doc, path) An object's member names, as a list[str].
json.Get_Str, json.Get_Int, json.Get_Float, json.Get_Bool (doc, path) The value at the path. A missing path or a value of another kind raises an error. Get_Str also accepts numbers and booleans and returns them as text.
json.Get_Str_Or, json.Get_Int_Or, json.Get_Float_Or, json.Get_Bool_Or (doc, path, fallback) The value, or fallback when it is missing or of another kind.
json.Get(doc, path) The object or array at the path as a json value for further calls. It is part of doc and must not be freed.
json.Set_Str, json.Set_Int, json.Set_Float, json.Set_Bool (doc, path, value) Sets the value, creating missing objects along the path. For arrays, an index equal to the length adds an element.
json.Set_Null, json.Set_Object, json.Set_Array (doc, path) Sets null, an empty object or an empty array.
json.Append_Str, json.Append_Int, json.Append_Float, json.Append_Bool (doc, path, value) Adds a value to the array at the path, creating the array if it is missing.
json.Append_Object, json.Append_Array (doc, path) Adds an empty object or array to the array at the path.
json.Remove(doc, path) Removes a member or element; returns whether it existed.
json.Free(doc), free(doc) Releases a document from Parse, Load, New_Object or New_Array.

To loop over an array, use its indexes:

for (i) in (range(json.Length(save, "player.items"))) : (
    println(json.Get_Str(save, "player.items[" + str(i) + "]"))
)

Member names that contain . or [ cannot be reached with a path.
