time

Call Result
time.Millis() Milliseconds on a steady clock, as int. Subtract two readings to time something.
time.Seconds() The same clock in seconds, as float.
time.Now() Seconds since 1 January 1970 (UTC), as int.
time.Year(), time.Month(), time.Day(), time.Hour(), time.Minute(), time.Second() Parts of the local date and time.
time.Weekday() 0 for Sunday to 6 for Saturday.
time.Format(pattern) Local date and time as text, using strftime codes: time.Format("%Y-%m-%d %H:%M:%S").
time.Sleep(milliseconds) Waits. In a program with a window, use os.Sleep instead so the window stays responsive.
time.Make(year, month, day, hour, minute, second), time.Make_Date(year, month, day) A moment in local time as seconds since 1970 (int), like time.Now().
time.Format_Time(moment, pattern) A moment as text, same codes as time.Format.
time.Parse(text, pattern) Reads a moment from text; understands %Y %m %d %H %M %S. Text that does not match raises an error.
time.Year_Of(moment), Month_Of, Day_Of, Hour_Of, Minute_Of, Second_Of, Weekday_Of Parts of a moment.
time.Add_Days(moment, days) The same time of day, days later (or earlier when negative), handling month ends and daylight saving.
time.Days_Between(from, to) Whole days between two dates.
