Optional values and none

T? is either a T or none. Fields, variables, parameters and return values can be optional.

class Node : (
    val value : int
    val next : Node?
)

val head = Node(1, Node(2, Node(3, none)))
val current : Node? = head
while (current != none) : (
    println(current.value)
    current = current.next
)

func find(items : list[str], wanted : str) : int? : (
    for (i) in (range(items.length())) : (
        if (items[i] == wanted) : ( return : int? (i) )
    )
    return : int? (none)
)

val position = find(["a", "b"], "z")
println(position.value_or(-1))                 // -1
  • A T can be used wherever a T? is expected.
  • x == none and x != none check for a value, as does x.has_value().
  • x.value() returns the value and raises an error for none; x.value_or(fallback) returns fallback instead.
  • Fields and methods of an optional class or struct can be used directly (current.value); doing so on none raises a catchable error.
  • A variable of a class type requires an object; declare it as Node? to allow it to start as none.
