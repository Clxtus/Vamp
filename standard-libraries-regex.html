regex

Patterns use the common regular-expression syntax: . any character, [abc] and [^a-z] sets, \d \w \s (and \D \W \S) for digits, word characters and whitespace, ^ and $ for start and end, \b a word boundary, ( ) groups, (?: ) non-capturing groups, a|b either one, and the repeats * + ? {n} {n,} {n,m} (add ? after a repeat for the shortest match). In a Vamp string the backslash is doubled: "\\d+".

Call Result
regex.Matches(pattern, text) Whether the whole text matches.
regex.Contains(pattern, text) Whether the pattern appears anywhere in the text.
regex.Find(pattern, text) The first match, or "".
regex.Find_All(pattern, text) Every match, as a list[str].
regex.Groups(pattern, text) For the first match: the whole match, then each group, as a list[str]. Empty when nothing matches.
regex.Replace(pattern, text, replacement) Replaces every match. $1 to $9 in the replacement insert groups, $$ is a dollar sign.
regex.Split(pattern, text) The pieces between matches. 
import regex
println(regex.Groups("(\\w+)@(\\w+)\\.com", "mail emma@example.com"))   // ["emma@example.com", "emma", "example"]
println(regex.Replace("(\\w+) (\\w+)", "hello world", "$2 $1"))           // world hello

An invalid pattern raises an error that describes the problem. Patterns are compiled once and reused.
