Control flow

if, else if, else

if (score >= 90) : (
    println("A")
)
else if (score >= 80) : (
    println("B")
)
else: (
    println("Keep practicing")
)

Conditions must be bool expressions.

while loops

val remaining : int = 3
while (remaining > 0) : (
    println(remaining)
    remaining -= 1
)

The condition is checked before each iteration.

for loops

val names = ["Emma", "Jake"]
for (name) in (names) : (
    println(name)
)

Arrays are iterated in index order. Iterating over a dictionary yields its field names in declaration order, and dictionary.values yields the values in that order. A for loop also iterates over lists (elements), maps (keys, in the order they were added) and strings (characters, as char).

Use range to count:

for (i) in (range(5)) : ( println(i) )            // 0 1 2 3 4
for (i) in (range(2, 6)) : ( println(i) )         // 2 3 4 5
for (i) in (range(10, 0, -2)) : ( println(i) )    // 10 8 6 4 2

range(stop), range(start, stop) and range(start, stop, step) take int values; stop itself is not included.

break and continue

In any while or for loop, break exits the loop and continue skips to the next iteration.

for (name) in (names) : (
    if (name == "") : ( continue )
    if (name == "stop") : ( break )
    println(name)
)

match

match compares a value against the patterns of each branch in order and runs the first branch that matches. A branch can list several patterns. else is optional and must come last; without it, a value that matches no pattern runs nothing.

match (key) : (
    "w", "up" : ( move(0, -1) )
    "s", "down" : ( move(0, 1) )
    else : ( println("unknown key") )
)

The value can be a number, str, char, bool or enum, and the patterns must be of the same type.
