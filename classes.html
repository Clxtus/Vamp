Classes

A class declares fields, methods and, optionally, nested classes. Class values are references: assigning one to another variable or passing it to a function creates a second reference to the same object, as in Python, Java and C#.

class Car : (
    val brand : str
    const max_speed : int

    class Engine : (
        const horsepower : int
    )

    func speed_with_bonus(bonus : int) : (
        return : int (self.max_speed + bonus)
    )
)

val car = Car("Vamp", 200)
val engine = car.Engine(450)
println(car.speed_with_bonus(10))
println(engine.horsepower)

The constructor takes the fields in declaration order. Methods receive self implicitly and are called with object.method(arguments). A nested class is constructed through an instance of the enclosing class.

val fields can be assigned (car.brand = "Other", or self.brand = "Other" inside a method). const fields cannot be changed.

Inheritance

class Child(Parent) inherits every field and method of Parent and can add its own. The constructor takes the parent's fields first. Redeclaring a method in the child overrides it, and super.method(...) calls the parent's version from inside the child.

class Animal : (
    val name : str
    func sound() : str : ( return : str ("...") )
    func describe() : str : ( return : str (self.name + " says " + self.sound()) )
)

class Dog(Animal) : (
    val breed : str
    func sound() : str : ( return : str ("Woof") )
    func parent_sound() : str : ( return : str (super.sound()) )
)

val dog = Dog("Max", "Beagle")
println(dog.sound())        // Woof
println(dog.name)           // Max

The method that runs depends on the object, not the variable, so a Dog stored in a list[Animal] still barks. A child object can be used wherever its parent class is expected.

val pets : list[Animal] = [Dog("Max", "Beagle"), Animal("Rocky")]
for (pet) in (pets) : ( println(pet.sound()) )      // Woof, then ...

== and != on class values compare identity: whether both refer to the same object.

Interfaces

An interface lists methods without bodies. A class names the interfaces it implements after its parent (or on their own) and must provide every method they list.

interface Shape : (
    func area() : float
    func name() : str
)

class Circle(Shape) : (
    val radius : float
    func area() : float : ( return : float (3.14159 * self.radius * self.radius) )
    func name() : str : ( return : str ("circle") )
)

class Square(Shape) : (
    val side : float
    func area() : float : ( return : float (self.side * self.side) )
    func name() : str : ( return : str ("square") )
)

val shapes : list[Shape] = [Circle(1.0), Square(2.0)]
for (shape) in (shapes) : ( println(f"{shape.name()}: {shape.area():.2}") )

class Button(Control, Clickable, Drawable) extends the class Control and implements two interfaces.

Overloaded methods, operators and printing

Methods can share a name when their parameter types differ, as with functions. A method named after an operator defines that operator for the class or struct: + - * / % take one value, == != < <= > >= take one value and return bool, and func -() with no parameters is negation. If only == is defined, != is its negation.

struct Vec : (
    val x : float
    val y : float
    func +(other : Vec) : Vec : ( return : Vec (Vec(self.x + other.x, self.y + other.y)) )
    func *(factor : float) : Vec : ( return : Vec (Vec(self.x * factor, self.y * factor)) )
    func to_str() : str : ( return : str (f"({self.x}, {self.y})") )
)

val v = Vec(1, 2) + Vec(3, 4) * 2
println(v)

func to_str() : str controls how a value is displayed by println, str(...) and f-strings. Without it, a class or struct prints its fields: Vec(x = 7.000000, y = 10.000000).

Iterators

A for loop can iterate over any class with a next() method that returns T?. The loop continues until next() returns none.

class Countdown : (
    val current : int
    func next() : int? : (
        if (self.current <= 0) : ( return : int? (none) )
        self.current -= 1
        return : int? (self.current + 1)
    )
)
for (n) in (Countdown(3)) : ( print(n) )        // 321

Generic classes and structs

Type parameters also work on classes and structs. The types can be written explicitly (Stack[int]) or inferred from the constructor values.

class Stack[T] : (
    val items : list[T]
    func push(value : T) : ( self.items.push(value) )
    func pop() : T : ( return : T (self.items.pop()) )
)

struct Pair[A, B] : (
    val first : A
    val second : B
)

val numbers = Stack[int]([])
numbers.push(1)
val reading : Pair[str, float] = Pair("pi", 3.14)

Structs

A struct is a record of fields and can have methods. Unlike a class, a struct is a value and is copied when assigned or passed.

struct Point : (
    val x : int
    val y : int
)

val start = Point(1, 2)
start.x = 10

func moved(point : Point, by : int) : Point : (
    point.x += by
    return : Point (point)
)

val end = moved(start, 5)       // start doesn't change
val origin : Point              // every field zero

Assigning, passing, returning or storing a struct in a list creates a copy. A method on a struct operates on the variable it is called on, so point.move(1, 2) changes point. Structs and classes can be fields of other structs and classes (val corner : Point), list elements (list[Point]) and map values. Structs do not support inheritance.
