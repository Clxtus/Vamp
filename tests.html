Tests

Tests are written in test "name" : ( ... ) blocks at the top level of a file. Normal builds exclude them. vamp test file.vp keeps the file's functions, classes and top-level variables, skips its other top-level code, runs each test separately and reports the result:

func add(a : int, b : int) : int : ( return : int (a + b) )

test "adds numbers" : (
    assert(add(2, 3) == 5)
    assert(add(-1, 1) == 0, "negatives cancel")
)

PASS  adds numbers

1 test, 0 failed

A failed assert or any uncaught error fails that test, and the remaining tests still run. vamp test exits with code 1 if any test failed.
