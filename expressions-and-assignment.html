Expressions and assignment

Operators Description
+ - * / % Arithmetic. % is the remainder and -x negates.
== != < <= > >= Comparison, producing a bool. Strings compare alphabetically; booleans and enums support only == and !=.
and or not Logical operators on bool values. and and or stop as soon as the result is known, so the right side may not run.
&& \|\| ! The same operators written as symbols: && is and, \|\| is or, ! is not. Either form can be used.
& \| ^ ~ << >> Bitwise and, or, xor, not, shift left, shift right, on whole numbers.

Precedence, from lowest to highest: or ||, and &&, not, comparisons, |, ^, &, << >>, + -, * / %, then unary - ! ~. Use parentheses when in doubt.

not applies to the whole comparison after it, so not lives == 0 means not (lives == 0). ! applies only to the value immediately after it, so it requires parentheses: !(lives == 0).

if (lives > 0 and not paused) : ( println("playing") )
if (lives > 0 && !paused) : ( println("playing") )   // equivalent
val low_bits : int = flags & 0x0F
val even : bool = count % 2 == 0

Variables, fields and elements can be updated with =, +=, -=, *=, /=, %=, &=, |=, ^=, <<= and >>=:

count += 1
player.score *= 2
scores[0] -= 5

Whole-number division or % by zero throws an error (division by zero), which can be caught with try.

Picking a value: a if condition else b

val label : str = "big" if size > 100 else "small"
val speed : float = 2.5 if boosted else 1

Both sides must have the same type. A number literal on one side takes the type of the other.

+ also concatenates strings:

println("count: " + str(count))
