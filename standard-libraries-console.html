console

Call Result
console.Read_Line() Waits for a line typed by the user and returns it without the line ending.
console.Read_Int(), console.Read_Float() Reads a line and converts it; text that is not a number gives 0.
console.Write(text) Prints without a new line (same as print).
console.Write_Error(text) Prints a line to the error output.
console.Clear() Clears the console window.
console.Set_Color(color) Text color 0 to 15 from the classic console palette (10 green, 12 red, 14 yellow, 15 white); -1 restores the default.
console.Set_Title(title) Sets the console window's title.
console.Flush() Forces pending output to appear.
