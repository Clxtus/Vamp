Events

Instead of a polling loop, a program can attach functions to events and let os.Run_Events() call them. It runs until every window the program created is closed, or until os.Stop_Events() is called.

import os

val window = os.Make_Window("Counter", ( style = "modern" ))
val counter = os.Make_Interface("label", "Counter", "count", ( size = (200, 30), position = (20, 20), text = "0" ))
val more = os.Make_Interface("button", "Counter", "more", ( size = (120, 34), position = (20, 60), text = "Add one" ))

val clicks : int = 0
os.On_Click("Counter", "more", func () : (
    clicks += 1
    os.Set_Interface_Text("Counter", "count", str(clicks))
))
os.On_Key("ESCAPE", func () : ( os.Stop_Events() ))
os.Every(1000, func () : ( println(f"{clicks} clicks so far") ))
os.Run_Events()
Call Description
os.On_Click(window_title, name, function) Calls function each time the button is clicked.
os.On_Key(key, function) Calls function each time the key is pressed (same key names as the input library, as a string literal).
os.Every(milliseconds, function) Calls function repeatedly at the given interval.
os.Run_Events(), os.Stop_Events() Start handling events; stop and continue after Run_Events().

The functions are func () values, either named functions or functions written inline. Calling On_Click again for the same button replaces its function.
