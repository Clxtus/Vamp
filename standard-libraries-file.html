file

Call Result
file.Read_Text(path) The whole file as a str. Raises an error if the file cannot be opened.
file.Read_Lines(path) The file's lines as a list[str].
file.Write_Text(path, text) Creates or replaces the file. Returns whether it was written.
file.Append_Text(path, text) Adds to the end of the file, creating it if needed. Returns whether it was written.
file.Exists(path) Whether a file (not a folder) exists.
file.Remove(path), file.Rename(from, to), file.Copy(from, to) Return whether the operation succeeded. Copy replaces an existing target.
file.Size(path) Size in bytes as int, or -1.

Relative paths are resolved from the program's working directory. Folders are handled by the os library.
