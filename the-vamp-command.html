The vamp command

Command Description
vamp file.vp Builds file.exe.
vamp run file.vp [arguments] Builds and runs it with the given arguments (read them with os.Args()).
vamp test file.vp Runs the file's test blocks.
vamp check file.vp Reports the first error without building; --json prints it for editors.
vamp format file.vp Prints the file with tidy indentation; --write saves it.
vamp symbols file.vp Lists the file's declarations as JSON, for editors.
vamp install <git address> [name], vamp remove name, vamp packages Manage packages.
vamp setup Checks for LLVM (clang) and the Visual Studio C++ build tools, which Vamp requires to build programs, and installs any that are missing with winget.
vamp setup --vscode Installs the Vamp extension in Visual Studio Code from the .vsix file next to vamp.exe.

Add --debug to vamp file.vp or vamp run to build with debugging information: the program is built without optimization and a .pdb file is written next to the .exe.
