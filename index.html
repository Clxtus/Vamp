Vamp documentation

Vamp is a compiled programming language for Windows. Programs are compiled through LLVM into small native .exe files that run at speeds comparable to C and C++, while memory is managed automatically.

class Player : (
    val name : str
    val health : int
    func hit(damage : int) : ( self.health -= damage )
)

val hero = Player("Ryan", 100)
hero.hit(25)
println(f"{hero.name} has {hero.health} health")

Install

  1. Download Vamp-<version>-x64.msi from the releases page and run it. It installs Vamp for the current user, sets up the Visual Studio Code extension and adds vamp to the PATH.
  2. On the last page, leave Download and install LLVM and the C++ build tools selected if they are not installed yet; Vamp requires them to build programs. They can also be installed later with vamp setup.
  3. Open a new terminal and run a program:
vamp run hello.vp

Your first program

Save this as hello.vp:

val name : str = "Vamp"

func greet(person : str, times : int = 1) : (
    for (n) in (range(times)) : ( println("Hello " + person) )
)

println(f"Hello from {name}!")
greet("Jake", 2)

vamp run hello.vp builds hello.exe next to the file and runs it. vamp hello.vp only builds it.
