Native interface controls

os.Make_Interface puts controls in a Vamp window. The window must be created first. The window title and control name must be string literals, and names must be unique within a window.

import os

val window = os.Make_Window("Search")

val search = os.Make_Interface("label", "Search", "query", (
    size = (260, 36),
    position = (20, 20),
    text = "",
    editable = true,
    text_color = "#202020",
    text_transparency = 1.0,
    background_color = "#FFFFFF",
    background_transparency = 1.0,
    font = "Segoe UI",
    text_size = 16,
    visible = true
))

val submit = os.Make_Interface("button", "Search", "submit", (
    size = (100, 36),
    position = (20, 66),
    text = "Search",
    visible = true
))

The call has this form:

os.Make_Interface(type, window_title, name, (properties...))

It returns true if the control was created. The parent must be a window created by the running program with os.Make_Window. Control types are "label", "button", "frame", "icon" and "canvas" (see Drawing on a canvas). size and position are required whole-number pairs, in pixels from the window's top-left corner. visible is optional and defaults to true.

Properties by control type

Property label button frame icon
size, position, visible, layer, group, style Yes Yes Yes Yes
corner_radius (modern style) Yes Yes Yes Yes
text Yes Yes No No
icon No Optional No Required
editable Optional No No No
text_color, text_transparency, font, text_size Yes Yes No No
background_color, background_transparency Yes Yes Yes Yes

An editable label is a text-entry field. A button requires exactly one of text or icon. Buttons with custom background settings are drawn by Vamp so the background can be blended; buttons without them are standard Windows buttons. icon is an image path (required for an icon control), resolved from the working directory. Windows and controls support ICO, PNG and JPEG images.

layer is a whole number, 0 by default. When controls overlap, higher layers are drawn in front, regardless of creation order. style and corner_radius are covered in Interface styles. Colors are "#RRGGBB" strings. Fonts are Windows font names, and text_size is a positive size in pixels. background_transparency goes from 0.0 (fully transparent) to 1.0 (fully opaque, the default when background_color is set); values in between set the opacity, so 0.9 is 90% opaque. The background is composited over whatever lies behind it. text_transparency works the same way and is controlled separately.

val panel = os.Make_Interface("frame", "Search", "panel", (
    size = (300, 160),
    position = (0, 0),
    layer = 0,
    background_color = "#000000",
    background_transparency = 1.0
))

val overlay = os.Make_Interface("label", "Search", "overlay", (
    size = (180, 60),
    position = (20, 20),
    layer = 1,
    text = "Overlay",
    background_color = "#FF0000",
    background_transparency = 0.5
))

Clicks can be checked in a loop:

while (true) : (
    if (os.Interface_Clicked("Search", "submit")) : (
        val query = os.Get_Interface_Text("Search", "query")
        println(query)
    )
    os.Sleep(16)
)

os.Interface_Clicked(window_title, name) returns true once for every click on that button, then false until the next click. To have a function called on each click instead, see Events. os.Get_Interface_Text(window_title, name) returns the current contents of an editable label. If the control cannot be found it prints an error and returns "".

Both functions require the exact window title and control name used when the control was created.
