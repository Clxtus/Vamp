Interface styles

Every window draws its controls in one of three styles, similar to Python's tkinter, ttk and CustomTkinter:

Style Look
"classic" The legacy Windows look: flat grey buttons, bold system font, labels on grey boxes.
"native" The default. Themed Windows 10/11 controls in Segoe UI, as in most Windows applications. Labels sit directly on the window and text boxes have a border.
"modern" Flat, rounded controls drawn by Vamp, CustomTkinter style: blue buttons that darken on hover and press (with a hand cursor), rounded text boxes that light up when focused, rounded frames, and a light or dark theme. 
val window = os.Make_Window("App", (
    size = (480, 320),
    style = "modern",
    theme = "dark"
))

val save = os.Make_Interface("button", "App", "save", (
    size = (140, 36),
    position = (20, 20),
    text = "Save"                       // accent blue in the modern theme
))

val delete = os.Make_Interface("button", "App", "delete", (
    size = (140, 36),
    position = (180, 20),
    text = "Delete",
    background_color = "#c0392b",       // custom colors still apply
    corner_radius = 18                  // half the height: a pill shape
))

val name = os.Make_Interface("label", "App", "name", (
    size = (300, 34),
    position = (20, 76),
    editable = true                     // a rounded text box
))

val legacy = os.Make_Interface("button", "App", "legacy", (
    size = (140, 36),
    position = (20, 130),
    text = "Old look",
    style = "classic"                   // one control can use a different style
))
  • The window's style is the default for its controls, and a control's own style overrides it. A window that sets style needs its title as a string literal.
  • corner_radius (whole pixels, 0 for square) works on modern controls. Defaults: 6 for buttons, text boxes and labels with a background, 8 for frames.
  • In the modern style every control has theme colors, so text_color, background_color and background_transparency are optional. When set, they replace the theme colors, and os.Set_Interface_Text_Color and the other setters work on every modern control, including buttons without a background.
  • A modern control fills its rounded corners with whatever lies behind it: the frame or colored control it sits on, or the window.
  • theme only affects "modern" windows. A native or classic control in a dark modern window keeps its own light look.
