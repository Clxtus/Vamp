Enums

An enum is a type with a fixed set of named values.

enum State : (
    Menu
    Playing
    Paused = 10
    Over
)

val state : State = State.Menu
state = State.Playing

match (state) : (
    State.Menu : ( println("menu") )
    State.Playing, State.Paused : ( println("in game") )
)

println(state)          // Playing
println(int(state))     // 1

Values count up from 0. = number sets a value explicitly, and later members continue from it. Enums compare with == and !=, print as their name, and convert with int(...) and str(...).
