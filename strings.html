Strings

+ joins strings, and str(value) turns any number, bool, char or enum into text. text[index] reads one character as a char. len(text) is the length in bytes.

Method Result
text.length() Length in bytes.
text.upper(), text.lower() Upper or lower case copy.
text.trim() Copy with spaces, tabs and new lines cut off both ends.
text.contains(part), text.starts_with(part), text.ends_with(part) bool.
text.find(part) Index of the first match, or -1.
text.replace(from, to) Copy with every from swapped for to.
text.split(separator) The pieces as a list[str]. An empty separator splits into single characters.
text.substring(start, count) count characters starting at start; a negative count means "to the end".
text.repeat(times), text.reverse() Repeated or reversed copy (reverse keeps characters like é in one piece).
text.char_at(index) Same as text[index].
text.is_number() Whether int(...) or float(...) can convert it.
text.char_count() Number of characters, counting multi-byte ones like é once.
text.chars() A list[str] with one entry per character (UTF-8 aware).
text.code_points() Each character's Unicode number, as a list[int]. 
val line : str = "  name = Emma  "
val parts = line.trim().split(" = ")
println(parts[1].upper())          // EMMA

String methods always return a new string and never modify the original. text[start:end] slices text the same way as lists.

Formatted strings

Prefixing a string with f allows values to be inserted with { }. Any expression can be used, optionally followed by a format after :: a width, an alignment (< left, > right, ^ centre) and, for floats, how many decimals.

val name : str = "Emma"
val price : float = 3.14159
println(f"{name} owes {price:.2}")              // Emma owes 3.14
println(f"|{name:<6}|{price:>8.1}|")           // |Emma  |     3.1|
println(f"{{braces}} and {name.upper()}")       // {braces} and EMMA

{{ and }} produce literal braces. Quotes inside the braces are written \", same as anywhere else in a string.

Building long text

Joining many pieces with + copies the entire text each time. A builder collects the pieces and builds the text once:

val report = builder()
for (i) in (range(1000)) : ( report.add_line(f"row {i}") )
println(report.text().length())

add(value) appends any value (numbers and other types are converted), add_line(value) also appends a new line (add_line() alone adds only the new line), text() returns the text, length() its length and clear() empties it.
