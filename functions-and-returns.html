Functions and returns

Functions take named, typed parameters, and the body is written in the second pair of parentheses:

func add(left : int, right : int) : (
    return : int (left + right)
)

func announce() : (
    println("Ready")
    return : void
)

return : type (expression) returns a value, return : void returns nothing. A function that returns a value must return on every path; a function that returns nothing may simply end.

The return type can also be written in the header, between the parameters and the body:

func average(left : float, right : float) : float : (
    return : float ((left + right) / 2.0)
)

Parameters and results can be any type. Numbers, strings and structs are copied. Classes, lists and maps are shared.

Default values

A parameter with = value can be omitted by callers. Parameters with defaults must come last.

func greet(name : str, times : int = 1) : (
    for (n) in (range(times)) : ( println("Hello " + name) )
)

greet("Emma")
greet("Emma", 3)

Overloading

Functions can share a name when their parameter types differ. The call selects the version that matches the arguments.

func show(value : int) : ( println("number " + str(value)) )
func show(value : str) : ( println("text " + value) )

show(3)
show("three")

A function can be called before the line that declares it.

Functions as values

Functions can be stored in variables, passed as arguments and returned. The type is func(parameter types) : result type; omit : result type for a function that returns nothing.

func twice(x : int) : int : ( return : int (x * 2) )

func apply(f : func(int) : int, value : int) : int : (
    return : int (f(value))
)

println(apply(twice, 21))                      // 42

val greet : func(str) = func (name : str) : (
    println("hi " + name)
)
greet("Jake")

func (parameters) : type : ( body ) without a name is a function written inline. It can use the surrounding local variables: it keeps its own copy of each one, taken when it is created, and changes it makes to that copy persist between calls.

func make_counter() : func() : int : (
    val count : int = 0
    return : func() : int (func () : int : (
        count += 1
        return : int (count)
    ))
)

val next_id = make_counter()
next_id()
println(next_id())                             // 2

Top-level variables are shared rather than copied, so changing one inside a function value changes it everywhere.

Generic functions

Square brackets after the name list type parameters. The types are inferred from the arguments, or can be written explicitly at the call.

func biggest[T](a : T, b : T) : T : (
    return : T (a if a > b else b)
)

println(biggest(3, 9))                         // 9
println(biggest("pear", "apple"))              // pear
println(biggest[float](1, 2))                  // 2.000000

Each combination of types is compiled separately, so generic code is as fast as code written for a single type.

Returning several values: tuples

(T, U) is a tuple type: a fixed group of values. A function can return one, and the caller can unpack it into several names.

func divide(a : int, b : int) : (int, int) : (
    return : (int, int) (a / b, a % b)
)

val quotient, remainder = divide(17, 5)
val pair = (1, "one")
println(pair[1])                               // one

Elements are read with a constant index such as pair[0]. Tuples cannot be modified after creation.
