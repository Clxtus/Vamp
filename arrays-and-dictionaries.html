Arrays and dictionaries

Arrays

val names = ["Emma", "Jake", "Lucy"]
println(names[0])

Arrays hold one type and have a fixed size. Elements can be read and written by index, but indexes are not bounds-checked and must be valid. For checked indexes and a variable size, use a list.

Dictionaries

val person = {Name : str = "Emma", Age : int = 31}
println(person.Name)

for (field_name) in (person) : (
    println(field_name)
)

for (field_value) in (person.values) : (
    println(field_value)
)

A dictionary is a record with fixed fields. Each field has a name and a type and is accessed with dictionary.FieldName. Arrays and dictionaries are stored inline, without extra allocation.
