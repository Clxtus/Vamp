Memory

Vamp manages memory automatically. Strings, lists, maps, sets, objects and function values are released once nothing refers to them; a garbage collector finds them while the program runs. It runs only after a significant amount of new memory has been allocated (16 MB at first), so short loops never pause, and arithmetic, structs and function calls never involve it.

When nothing else uses a string, list, map, set or object, free(value) releases it immediately; it must not be used afterwards. The memory library reports on and controls the collector:

Call Result
memory.Collect() Frees everything that is no longer used immediately. Useful between levels or after loading.
memory.Used() Bytes currently used by Vamp values, as an int.

Native memory

malloc(type, count) allocates native storage for a number of elements of any storable type (numbers, bool, char, str, structs). In most programs, a list is easier and safer.

val values = malloc(int, 4)
values[0] = 42
println(values[0])
free(values)

Pointer indexes are not bounds-checked. Initialize memory before reading it, stay within the allocated count, and call free exactly once. Do not use a pointer after freeing it.
